# Bangladesh Arrival Gateway | web presentation

Standalone HTML, CSS and JavaScript presentation prepared for Tourifye.

This revised 15-scene narrative gives dedicated focus to the declared accommodation, verified visitor-safety information, national tourism promotion, and an optional hotel/destination partner marketplace kept separate from the mandatory government service.

## Open it

For the most reliable local preview, serve this folder with any static web server and open `index.html` through that server. The presentation has no package installation or build step.

## Controls

- Arrow keys, Space, Page Up / Page Down: navigate
- `O`: slide index
- `S`: evidence and source notes
- `F`: fullscreen
- `P`: print or save as PDF
- Home / End: first or final slide

The deck also supports on-screen controls and horizontal swipe gestures.

## Structure

- `index.html`: presentation content and sources
- `styles.css`: visual system, layouts, motion and print rules
- `presentation.js`: navigation, drawers, fullscreen, swipe and chart rendering
- `assets/`: Tourifye logos, custom imagery and locally hosted fonts

All research links appear in the per-slide Evidence drawer. Operational details should be rechecked before an external presentation.
